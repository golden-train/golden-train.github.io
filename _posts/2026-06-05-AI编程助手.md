在本节，我们将介绍一些AI编程助手工具，这些工具可以帮助您更高效地进行编程工作。无论您是初学者还是略有经验的开发者，这些工具都能为您提供有价值的支持。如果您是在校大学生，您可以申请GitHub Copilot的学生版，享受免费的AI编程助手服务。本教程中将使用deepseekV4作为演示，它的价格亲民，在国内访问速度极快，支持1[M]上下文功能也非常强大，适合各种编程需求。

1.本次，我们将采用IDEA的CC GUI插件做为我们的agent助手，您需要按找mineraft的扩展方法在IDEA的插件中安装CC GUI插件，安装完成后，您需要在IDEA的设置中找到CC GUI插件的设置界面（一般在侧边栏），初次使用需要下载codex或者cloude code 是安装包，您可以按照流程安装，在校园网等特殊环境中安装可能会失败，您一般情况下，通过手机热点就可以成功安装了。

2.如果您提示需要node，这说明您没有安装node环境，您可以访问node的官网[https://nodejs.org/zh-cn/download/](https://nodejs.org/zh-cn/download/)下载并安装，安装完成后，您需要在IDEA的设置中找到CC GUI插件的设置界面，在其中找到Node Path选项，点击右侧的文件夹图标，选择您安装的node路径（一般在C:\Program Files\nodejs\node.exe），选择后点击确定即可。（注意，这和Node.js几乎无关，社区版同样可以使用node）

3.在安装codex或者cloud code的过程中，您可能会遇到一些问题，例如下载失败或者安装失败，若您切换网络后任然无法安装，则可能是node的权限不足导致的，您可以尝试以管理员身份运行IDEA，或者通过npm，将其缓存地址迁移到其它地方有权限的地方，例如：

    npm config set cache D:\npm-cache --global
    npm cache clean --force  # 清除缓存

当然，您也可以采用配置npm更高权限来解决 # 此处举例，请参考实际安装路径

    npm config set prefix D:\npm-global --global
    npm config set cache D:\npm-cache --global
    npm cache clean --force # 清除缓存

4.安装完成后，您的cc GUI应该就可以正常使用了，但此时，它使用的是其它的大模型，如果您有对应的大模型账户，您可以忽略这一步；如果您使用包括字节，腾讯等国内大模型，您同样可以参考下面的步骤进行配置：
（1）下载cc switch[https://github.com/farion1231/cc-switch/releases](https://github.com/farion1231/cc-switch/releases)
安装完成后按流程录入相关信息，关于API的获取，网上的教程已经相当完善，您可以自行搜索。
