2.现在，在完成neoforge的环境安装后，我们需要导入机械动力的相关依赖。
首先，访问机械动力扩展的官方网站[https://wiki.createmod.net/developers/depend-on-create/neoforge-1.21.1](https://wiki.createmod.net/developers/depend-on-create/neoforge-1.21.1)在这里，给出了你需要添加的代码和位置
其次，我推荐您同时安装JEI扩展（可选项目，在我提供的代码中已安装，您可以自行搜索它的官方指导文档，需要注意，官方文档中的jc-version没有被注册为宏变量，您需要手动添加到gradle.properties中，同时，使用的MC版本宏变量名与实际并不相同，注意修改，在下面提供的代码中已经改正）
在这里，我将列出集体需要修改的代码块

1.build.gradle（添加在repositories块中）
    
    maven { url = "https://maven.createmod.net" } // Create, Ponder, Flywheel
    maven { url = "https://maven.ithundxr.dev/snapshots" } // Registrate
    // Add here additional repositories if required by some of the dependencies below.
    maven {
        // location of the maven that hosts JEI files since January 2023
        name = "Jared's maven"
        url = "https://maven.blamejared.com/"
    }
    maven {
        // location of a maven mirror for JEI files, as a fallback
        name = "ModMaven"
        url = "https://modmaven.dev"
    }

2.build.gradle（添加在dependencies块中）
    
        implementation("com.simibubi.create:create-${minecraft_version}:${create_version}:slim") { transitive = false }
        implementation("net.createmod.ponder:ponder-neoforge:${ponder_version}+mc${minecraft_version}")
        compileOnly("dev.engine-room.flywheel:flywheel-neoforge-api-${minecraft_version}:${flywheel_version}")
        runtimeOnly("dev.engine-room.flywheel:flywheel-neoforge-${minecraft_version}:${flywheel_version}")
        implementation("com.tterrag.registrate:Registrate:${registrate_version}")
        /* other minecraft dependencies are here */

        // compile against the JEI API but do not include it at runtime
        compileOnly("mezz.jei:jei-${minecraft_version}-neoforge-api:${jei_version}")
        // at runtime, use the full JEI jar for NeoForge
        runtimeOnly("mezz.jei:jei-${minecraft_version}-neoforge:${jei_version}")

3.neoforge.mods.toml
>路径src/main/templates/META-INF/neoforge.mods.toml
直接复制粘贴到最后

    [[dependencies.${mod_id}]]
        modId="create"
        type="required"
        versionRange="[6.0.10,6.1.0)"
        ordering="NONE"
        side="BOTH"
4.gradle.properties 同样复制到最后

    create_version = 6.0.10-280
    ponder_version = 1.0.82
    flywheel_version = 1.0.6
    registrate_version = MC1.21-1.3.0+67
    jei_version=19.27.0.340

现在，导入全部代码后按刚才的方式刷新，等待构建完成后
