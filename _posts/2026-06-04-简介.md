> 本教程基于 MC 1.21.1 和 NeoForge。

本文章是为略有编程基础制作的有关机械动力扩展的相关教程。如果您对 JAVA 开发或者程序编写没有任何基础，那么建议您先学习 JAVA 开发的基础。机械动力的 mod 开发与原版 mod 具有一定的区别，同时难度略高一些，如果可行，您可以先行学习 MC 基础的 mod 开发。如果您非常熟悉 JAVA 和 MC mod 开发，本教程同样不适用，您可以查询官方手册，以获得更加权威、准确的指导。

声明：本人是一名非计算机专业的大学生，mod 开发纯属爱好，讲解必定有疏漏和错误，如有发现敬请指出。
