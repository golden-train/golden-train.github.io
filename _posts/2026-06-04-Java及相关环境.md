1.JAVA的安装：
JAVA 是机械动力和MCmod开发的基础环境，您需要安装JAVA开发工具包（JDK）请不要下载JAR，这将导致您无法进行下一步操作。在1.21.1中建建议必须安装21及以上版本，但使用21以上的其它版本例如25会有时出现问题，为确保兼容性和性能，若您对计算机了解较少，请下载JDK21。[oracle 官方 JDK 21下载链接](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)
[![](/assets/img/001.jpg)](/assets/img/001.jpg)
下载完成后打开，安装路径建议设置建议默认，

> 在现代化的编辑器中，几乎都支持自动搜索，您可以先保留此步骤，如果后续无法找到再进行安装完成后需要配置环境变量，右键此电脑-属性-高级系统设置-环境变量，在系统变量中找到Path，点击编辑，添加新的环境变量：C:\Program Files\Java\jdk-21.0.2\bin，点击确定保存。完成后打开命令行输入java -version，如果显示出JAVA的版本信息，说明安装成功。（此处略写，[点此访问详细教程](/posts/JAVA环境变量/)）

2. 相关环境的安装：
JAVA环境搭建完成后，您需要一个好用的现代化的编辑环境，这里推荐使用IntelliJ IDEA，您可以在官网上下载社区版它完全免费，如果您拥有学校的邮箱（包含.edu）您可以申请IDEA的专业版使用，这里使用社区版的功能就足够了。[IntelliJ IDEA下载链接](https://www.jetbrains.com/idea/download/#section=windows)
[![](/assets/img/002.jpg)](/assets/img/002.jpg)
安装完成后，您应该见到如下界面，这里我已经提前下载了，所以有其它项目，如果您是第一次使用，应该是空白的。
>新版本IDEA已经默认捆绑中文安装包，如果没有自动安装，您可以在插件市场（Plugins中选择Marketplace）下一步所在地中搜索Chinese进行安装，安装完成后重启IDEA。
[![](/assets/img/003.png)](/assets/img/003.png)
接下来我们需要安装一些插件来帮助我们进行开发，点击File-Settings-Plugins，（Plugins中选择Marketplace）
[![](/assets/img/004.png)](/assets/img/004.png)
在搜索框中输入Minecraft Development，找到后点击安装，安装完成后重启IDEA。
[![](/assets/img/005.png)](/assets/img/005.png)
